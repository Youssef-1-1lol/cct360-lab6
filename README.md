# Outside Now

CCT360 Lab 6 — Working with API. A weather window built with plain HTML, CSS and JavaScript.

## Plan

Fetch current weather from the public Open-Meteo API. Turn the returned weather into a changing landscape, with a city selector, temperature units, refresh and motion control.

Development started November 9, 2026 outside class. Commits document actual milestones; they are not backdated class attendance records.
